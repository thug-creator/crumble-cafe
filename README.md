# Crumble Cafe - Одностраничный сайт

## О проекте
Проект представляет собой SPA (Single Page Application) для кафе. Контент генерируется динамически с помощью JavaScript-модулей. Переключение между вкладками происходит без перезагрузки страницы.

## Выполненные задания:
- **Уровень 1:** Добавлена вкладка "Контакты", настроена стилизация (Google Fonts, hover-эффекты), реализовано выделение активной вкладки.
- **Уровень 2:** Данные меню вынесены в JSON-файл, добавлены изображения блюд (настроены asset modules в Webpack), добавлена кнопка "Забронировать столик".
- **Уровень 3:** Реализована форма обратной связи с валидацией полей (имя и email), добавлен счетчик посещений вкладки "Меню" (localStorage), добавлена плавная анимация переключения вкладок (fadeIn).

## Как запустить проект:
1. Установите зависимости:
   `npm install`
2. Запустите сервер разработки:
   `npm start`
3. Проект откроется в браузере по адресу `http://localhost:8080/`.
